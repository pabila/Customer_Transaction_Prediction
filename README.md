# Heart Disease Prediction
## Project Overview
This project predicts whether a person has heart disease using machine learning models.
The goal is to help in early detection and support medical decision-making.

## Objective
Build a classification model to predict heart disease
Compare multiple ML models
Identify the best performing model
Dataset
Contains patient health details
## Target variable:
0 → No Heart Disease

1 → Heart Disease
## Models Used
Logistic Regression,
Random Forest,
Gradient Boosting,
XGBoost.
## Evaluation Metrics
Accuracy,
Precision,
Recall,
F1 Scor,e
ROC-AUC.
## Best Model
XGBoost performed best with highest ROC-AUC and recall.
